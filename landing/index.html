NRC nuclear documents, one function call away.

A typed, validated Python client for the NRC ADAMS API. NUREGs, letters, inspection reports and Part 21 notices — searched in minutes.

Get startedView on GitHubDocumentation
from adamsnrc.main import content_search

result = content_search(
    properties_search=[("DocumentType", "ends", "NUREG")],
    single_content_search="steam generator",
    sort="DocumentDate", order="DESC",
)
for doc in result.results:
    print(doc.get("title"))

Quick start

Install, import, search.

# high-level helpers
from adamsnrc.abstractions import find_nureg

docs = find_nureg("steam generator")
# configure via environment
export ADAMS_TIMEOUT=60
export ADAMS_MAX_RETRIES=3
export ADAMS_LOG_LEVEL=INFO
